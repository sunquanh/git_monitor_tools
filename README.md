# Git 仓库监控工具

多仓库 Git 状态实时监控工具：一个页面看遍所有仓库的分支、提交、工作区状态，顺手完成暂存、提交、分支、Stash、标签、冲突解决等日常操作。**零第三方依赖**——Web 版自带 Flask 兼容层，拷过去就能跑。

当前版本：v3.2.3

## 功能一览

- 📊 **仓库监控**：多仓库状态卡片（分支、提交、领先/落后、健康度），自动刷新
- 🔧 **工作台**：文件级 / hunk 级 / 行级暂存，提交、丢弃、储藏一气呵成
- 🔀 **分支比对**：开发分支 vs 生产分支差异，支持发布快照与 CHANGELOG 导出
- 🕸 **提交图**：可视化提交历史，支持缩放与点击定位
- 📈 **统计**：作者排行、提交热力、DORA 指标
- 🌿 **分支 / 📦 Stash / 🏷 标签**：完整的创建、切换、删除、推送管理
- ⚠ **冲突解决**：ours / theirs / both 三策略 + diff3 三方对照 + 手工精修
- 🔍 **仓库体检**：体积统计、大文件排行、敏感信息扫描
- ⌨️ **键盘流**：`/` 全局搜索、`g` 前缀跳转 13 个视图、`Ctrl+K` 命令面板（含拼音首字母）

## 快速开始

### Web 版（推荐）

```bash
# Windows：双击 启动.bat；其他系统：
python git_web.py
```

浏览器自动打开 `http://127.0.0.1:8420`。服务只监听本机回环地址。

### 桌面版（tkinter）

```bash
python git_monitor.py
```

## 配置

编辑 `git_monitor.json`，在 `repos` 里添加仓库（名称 → 本地路径）：

```json
{
  "repos": {
    "my-project": "D:\\code\\my-project"
  }
}
```

首次启动后也可以在页面右上角 ⚙ 设置里图形化管理。详见 [`使用说明.md`](使用说明.md)。

## 项目结构

```
git_web.py          Web 版后端（99 个 API 路由）
web/index.html      Web 版前端（13 个视图，5 套主题）
git_monitor.py      桌面版（tkinter）+ Git 操作函数库（被 Web 版复用）
flask_compat.py     标准库实现的迷你 Flask 兼容层（无 pip 依赖的关键）
git_monitor.json    配置文件（仓库列表、主题、刷新间隔等）
```
